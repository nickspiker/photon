**Nick 2026-09-17:** "We have a weird tiered image viewer that is quite irritating. We need to implement the same interface opsin has in Photon for the image viewer, DNG and all, exposure slider, etc. We just need to add back/escape button plus top left back arrow to exit."

**Shape (shipped, photon + opsin + fluor commits of 2026-09-17):** opsin's `app.rs` was split into `view.rs` (`View` — the whole viewer: pan/zoom/crop/rotate, right panel = navigator, 1:1/Fit/export/Info + CCW/CW/Crop rows, raw histogram with HDR/X/Y/Clip pills, exposure slider −4..+12 EV, chromaticity chart, frame-info HUD, every key) and a thin `OpsinApp` shell (chrome, bar, window ops, folder ←/→, IDT clipboard, instance socket, `[]` chord). `View` is AREA-relative (`set_area(Area)`), takes host-allocated hit ids (`View::new(loaded, &mut hit_counter)`), stamps into the host's hit map at `render(canvas, viewport, text, damage_clip, cursor, hit_map)`, answers `on_event(event, ctx, hit)` with `Handled | Close (Escape) | Pass (dead panel space / backdrop / unbound key)`; `zoom_around` for the host's pinch/Ctrl+wheel; wheel Pixels = PAN, Lines = ZOOM (was zoom for both — opsin desktop trackpad scroll now pans). opsin feature `view` = fluor without host-winit (Android builds it); `viewer` = view + winit. `Loaded::from_decoded(dec, meta, name, size, max_edge, keep_decode)` folds the display copy (photon: 2048 phone / 4096 desktop) while `RawView` keeps full sensor counts with a fold bridge (`or_w/fold_w`); rotation turns `lin` directly (no decode needed) so a phone drops `dec`.

**Photon wiring:** `viewer.rs` `Viewer { view: Option<View>, decoding, failed }`; `request_view_decode` → worker: opsin sniff Unknown? → `attach_preview::legacy_linear_planar` (image crate, PNG/GIF/BMP) → `opsin::convert::ingest_linear_vsf_rgb`; else temp file → `opsin::view::load_image_folded`. `drain_img_view` builds the View on ids `viewer_view_base` (16 reserved after `viewer_base`'s 8), export pill relabelled "Save" → `take_export_request` → `viewer_save`. driver.rs forwards CursorMoved/MouseInput/MouseWheel/Keyboard/Focused to the view FIRST (skipping photon's own Back/Save pill hits, arrows, Shift+Esc); `on_zoom` → `zoom_around`; `cursor_for` asks the view; `visit_app_widgets` yields the view's widgets in Conversation. render.rs viewer band: swallow-restamp the area first, draw Back/Save pills, then `view.set_area` + `view.render` (area = below chrome strip / Android safe top); interim (no view yet) = preview/micro fitted + "decoding…"/"fetching" caption. Removed: `open_in_opsin` (external spawn), `full_image_linear`/`encode_linear`, `viewer_lin`, `img_linear_*`, Msg `ViewerOriginal`/`ClipPill`/`ExposureStops` (all 17 catalogs).

**Keep in sync:** a new View widget → bump `VIEW_HIT_IDS` (16) if the count passes it; View labels are opsin's English (an instrument's labels, not translated) except the export pill; EV/magnification readouts are arabic decimals (dozenal doctrine not applied inside the view yet).
