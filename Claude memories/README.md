# Claude memories — photon

The assistant's persistent memory for photon, kept in the public photon repo and shared by every machine ([[push-after-landing]]).
`MEMORY.md` is the index; each other file is one memory with YAML frontmatter.

- `git pull` photon before acting on memory; commit and push memory edits with the session's photon commits.
- A `MEMORY.md` merge conflict resolves by UNION — keep every index line from both sides.
- Never write a handle here ([[no-private-handles]]); people appear by petname.
