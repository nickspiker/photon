The PIPE genesis **ceremony** is *whakaira* (whaka- causative + *ira* = "bring the ira into being"), NOT *ihi*.
The patent was renamed ihi→whakaira (2026-06; pipe/patent/patent.tex, incl. the `whakaira` claim label and `whakairasnap` figure label) to clear a collision with the `ihi` crate.

*ihi* everywhere in the stack means the **outwardly-perceptible quality of mana** — the verifiable identity (ihi crate = handle_proof/spaghettify; ferros oracle output; manifestus/custodes "app's ihi"). Never use *ihi* for a ceremony.

Other fixed terms: *ira* = permanent device identifier (interim: derived from SoC HUK at EL3; endgame: whakaira-burned); *wairua* = per-session secret (TRNG → crypto register, volatile); states KORE=00/WHARA=01/HARA=10/ORA=11 + NGARO (silent, no code); whakaira sub-steps KOHI/HORO/TATARI/TAHU; *motuhake* = test domain.

Canonical cross-stack source: **ferros/GLOSSARY.md**. Patent is authoritative for the hardware terms; each crate README owns its own name's etymology.
