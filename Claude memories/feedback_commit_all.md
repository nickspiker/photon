name: Commit all changes when asked
description: When Nick says commit and push, include all modified files unless he specifically excludes something

---

When Nick asks to commit and push, commit all modified files — don't selectively skip files assuming they're "in-progress work."

**Why:** Nick expects all changes to be included. Cherry-picking without being asked is presumptuous.

**How to apply:** Only exclude files from a commit if Nick explicitly says to leave them out.
